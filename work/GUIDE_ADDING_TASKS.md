# 新しいタスクを追加するガイド（Codex向け）

## いつタスクを増やすべきか
- 仕様が増えた（例: 画像入力、時系列、マルチターゲット）
- バグ修正が複数ファイルに跨る
- 既存タスクが巨大化してレビュー不能

## 追加手順（必須）
1. `work/tasks/Txxx_*.md` を作る（テンプレ: `work/templates/TASK.md`）
2. `work/queue.json` に登録
   - `depends_on` で順序を明確化
   - `skills` と `contracts` を必ず書く
   - `must_change_globs` を設定（例: `src/**`）
3. docsが変わるなら `docs/` も更新タスクを作る

## 重要: “作りっぱなし禁止”
- タスク追加と同時に不要ファイル削除ルールも明記すること
